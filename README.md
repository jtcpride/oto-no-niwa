## v0.33 語頭の見直し・戻せる音声方式・七人の造形（2026-10-04）

単語の声を、語頭の間を減らす候補 `af_kore` へ変更し、話速と先頭無音を調整しました。音素や教材は変更せず、mother の /m/ や she の /ʃ/ は削っていません。聞き心地は [以前の端末音声／v0.32／新しい声の比較ページ](docs/evidence/voice-v033/index.html) で判断できます。

音声は可逆です。`content/voice-config.js` の `engine` 一か所で `recorded` と `native` を切り替えられます。`?voice=native` は以前の端末読み上げ、`?voice=recorded` はBGMと同じWeb Audioでの音源再生。URL指定は保存せず、外せば既定値へ戻ります。旧方式ではiOSの音声セッションによるBGM中断が再発する可能性があり、実機の聴感は未確認です。

参考画を基に、七人の顔の比率・髪・襟と袖・手足を実モデルで繰り返し調整。ゲームの学習操作、関節の接触、ラリーの時間や判定は維持しています。[参考画と実モデルの比較](docs/art/v033/index.html)／[音源と再生成手順](audio/voice-v033/README.md)／[変更・比較・検証の記録](docs/PROJECT_HANDOFF.md)。

## v0.31 Three.js（2026-10-04）

Three.js版を公開対象としています。制作ブランチは `migration/threejs-renderer` です。七人の面付き造形、回し蹴りの腰と上体の反動、蹴りの引き戻し、鞠の曲面と縫い帯、接地影・輪郭の照明を調整しました。発音時にBGMが過剰に下がる問題を直し、自分と相手の蹴り音は旧電子音へ戻しました。教材・ラリー時間・判定・ダメージ・試合形式は維持しています。

[約19秒の変更前後比較（左が前、右が後／無音）](docs/evidence/three-polish-2026-10-04/comparison.mp4) · [七人の造形](docs/evidence/three-polish-2026-10-04/characters.png) · [引継ぎ・検証と未確認範囲](docs/PROJECT_HANDOFF.md)

## Previous published baseline

- **v0.29.1「関節・動作・鞠・接触の調整」**（公開試遊版）
- 両キャラに肘・手首・つま先の左右6関節を追加。蹴りで肘を畳み、ガードで腕を上げ、足先で踏ん張る。現行の低ポリ造形を維持
- 試合の流れ・判定・球道・描画品質を維持し、蹴りの振り抜き/引き戻し、軸足と腕の釣り合い、鞠の回転、接触点の短いエフェクトを改善
- 前半の突破球を溜めて強く蹴り、相手が奥へ吹き飛ぶ。自分が走って追い、カメラが背後へ回ってから横ビューへ戻る
- 近接のIPAは頭・胸・腹・脚の前面に重ねた丸で表示。蹴りの足先もその丸の位置へ合わせ、防御と直撃で身体反応・接触音を分ける
- 一ノ庭の奥舞台で最後の正解返球から近接へ。防御→攻撃×2、4音ボタンで即回答。3/4正解で溜め→ラッシュ、2/4以下は押戻し→通常ラリー。正解返球2回で再挑戦
- 近接は頭・胸・腹・脚に4音を固定対応、正解部位は回答後だけ表示。1問3.2秒、HPを直接減らさず、連打では勝てない
- 自分のHP下にPERFECT・連続PERFECTなどの評価を再表示。最新一件だけ約1秒表示し、正解カードと併記
- 一ノ庭は成功着弾の短い間→相手先行の奥への崩れ→追い足→成功に応じた接近とカメラの寄り→溜め→Vocabulary Rush→着弾の余韻へ
- 前半・練習の飛行時間は維持。後半は距離に比例して飛行時間を短縮（距離換算に0.18秒を足し、最短1.85秒）、OK判定を最大±0.34秒へ拡大。PERFECTは±0.065秒のまま。ラッシュは毎タップ攻撃し、前の発音を即キャンセルして次の語を読む（待ち列なし、ユーザー指定により元の形へ）
- TIME後、礼をせず5秒待つと礼ボタンの金色の枠がゆっくり明滅。演出OFF・視差効果を減らす設定では静止した枠で案内
- ラッシュは既存4技を順に繰り出し、一押しで3つの鞠が複数方向から相手へ集中。単語は画面内へ分散し、0.3秒表示後0.25秒でフェードアウト。演出OFFは1球・1語に抑える
- 奥舞台は以前より広い間合いから開始。蹴った側だけが振り抜いた後に一歩進む。左右別管理で、空中の鞠の出発点は動かさない
- 奥舞台では中段への突き・回し蹴り・大きな蹴り上げ・振り下ろしを両者に適用。通常球速を基準に後半の距離から飛行時間を算出
- 一ノ庭のみを調整。二ノ庭のv0.22演出は維持。試遊・比較証拠は [引継ぎ冒頭](docs/PROJECT_HANDOFF.md) を参照
- 相手HPが半分以下になる返球で溜め・突破、一ノ庭の奥舞台へ追走。後半は成功返球で接近（加速は最短1.85秒で制限）
- 最後の返球は0.7秒の溜め→高速の鞠→5秒の連打ラッシュ→SHOUBU ARI。一ノ庭では開始前と最終着弾後に短い間を置く
- 奥舞台は現行の低ポリ描画による仮背景。完成版の京都美術ではない
- 最大7ステージの定義に対応。デッキ・単語/IPA・自キャラ・敵キャラ・描画リグを分離
- 現行の一ノ庭に加え、`/f/ /v/ /s/ /z/` の二ノ庭を選択可能。背景は共用
- [ステージの追加・差し替え手順](docs/STAGE_MODULES.md)
- 左上と開始画面のタイトルを二段組へ。STARTで単語と同じ音声がタイトルを読み上げ、終了後にプレイ開始。消音・未対応時はそのまま開始
- 初期音量はBGM 80％／発音85％。発音中もBGMを60％残し、効果音は下げない。ゲーム音の共通ゲインを0.22→0.32へ調整（実機の聴感は未確認）
- TIME後の鞠は床上の移動距離に合わせて回転し、消えていく
- 勝利時はHAJIMEと同じ英語音声設定で「Shobu ari!」を一度だけ読み上げ
- 縦画面は下部に発音記号4個を横並び、横画面は左側に縦並び・右下に返球ボタン
- 横画面のタイミングバーは中央ステージの下。画面回転でも記号の順番・選択状態を維持
- 本編は時間制限・返球数で終了せず、相手の体力0で勝利、自分の体力0で敗北
- 正しい返球が相手に届くと10ダメージ、PERFECTなら15ダメージ。練習は双方ダメージなし
- 開始画面の説明とプレイ中の飾り文を減らし、iPhoneではダイアログをステージ下側にコンパクトに表示
- 横タイミングバーを反転し、相手側を右・蹴りどきを左（自分側）に配置
- 1ステージ4音。一ノ庭: `/θ/ /ð/ /ʃ/ /ʒ/`、二ノ庭: `/f/ /v/ /s/ /z/`
- CPU側で英単語を読み上げ、狙った音の発音記号を選んで返球
- 試合前に4音×2周のPRACTICE
- PRACTICEでは代表語・語全体IPA・対象記号を中央に提示
- 8球後に `TIME` を音声でも告げ、見送り球はプレイヤーの後方へ転がる
- `礼` をするとCPUも礼。礼後は長めの間を置き、英語話者TTSの `HAJIME!` で本戦へ
- 礼後の待ち時間中に再度礼すると、HAJIMEまでの間がリセットされる
- 正解・不正解とも、中央に単語・IPA・正解記号を表示して視線を固定しやすくした
- ミス時は「よろめき蹴り」ではなく、身体に当たって跳ね返る BODY RETURN 表現
- 間違えた問題は数問後に再登場する簡易リトライキューを追加
- 3回連続ミスは一歩よろけて復帰（旧転倒演出の重複を除去）
- 記号選択で浅い円弧を回り込む足運び
- BGM / 発音を個別調整。発音中はBGM・効果音を自動的に抑える
- BGMは楽器数を滑らかに増やし、音が重なるほど音量を補正
- 浮かし / 内回し / 外払い / すくい上げ。膝の曲げ伸ばしと構え・振り抜き・復帰
- 技と入力タイミングが球の高さ・速さ・奥行きの曲がり・回転に反映
- LOB / PERFECT / DRIVE、体力・救済ラリーは継続
- 発音そのものの録音・採点はまだ未実装

この段階ではゲーム性と学習ループの検証を優先します。
