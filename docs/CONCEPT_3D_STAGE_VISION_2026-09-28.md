## 0. 一文コンセプト

**発音記号を蹴り技として身体化し、正解ラリーによって音・速度・間合い・映像が同時に高まり、最後には語彙を必殺技のように浴びせかける、京都を大胆に再構成した1対1蹴鞠格闘学習ゲーム。**

学習問題を解いてからゲームをするのではなく、**正しく音を聞き分け、記号を選び、身体的に反応する行為そのものが戦闘になる**ことを狙う。

---

# 1. 体験仮説

## 1.1 発音記号を「技」にする

発音記号を読む対象ではなく、蹴り技・構え・身体位置に対応させる。

理想的には、

1. 単語を聞く
2. 音素を認識する
3. 対応するIPAを思い出す
4. 対応する身体位置 / 蹴り技へ移る
5. タイミングを合わせて返球する

という連鎖が、反復によって

> 「/æ/ならこの蹴り」

のような即時反応へ近づくことを狙う。

---

## 1.2 正解が世界そのものを盛り上げる

点数やバッジではなく、**正答行動によってゲーム体験そのものが豊かになる**設計を重視する。

連続成功すると、

- 鞠が速くなる
- 音楽が厚くなる
- 効果音が強くなる
- カメラが寄る
- 二人の距離が縮む
- 観客や背景が盛り上がる
- エフェクトが増える
- 戦いが近距離化する

という変化が同時に起きる。

内部変数の仮称: **Rally Heat**

---

## 1.3 ラリーが「間合い」に変換される

ラリー継続を単なるコンボ数にしない。

遠距離では:

- キャラクターは小さい
- 背景がよく見える
- 返球時間に余裕がある

成功が続くと:

- 二人が実際に3D空間で近づく
- 球の飛行時間が短くなる
- 反応猶予が減る
- カメラが寄る
- 呼吸・足音・水飛沫など身体感が強くなる

最終的には、あと一歩詰めれば直接蹴りが当たる距離へ入る。

感覚としては、言葉を応酬しながら互いに一歩ずつ前へ出てくる**ラップバトル的な圧縮**に近い。

# 2. 基本ゲーム構造

## 2.1 遠距離ラリー

- 発音記号 / 音素に対応する単語がCPU側から提示・発声される
- プレイヤーは対応するIPA / 技を選択
- タイミング良く蹴る
- 成功時、その音を含む単語やIPAが視覚・音声で再提示される
- CPUが返球
- 成功が続くほどRally Heat上昇

現行の「聞いて選ぶ + 蹴る」ループを、そのまま高度化する。

---

## 2.2 近距離発音格闘

距離が十分に詰まると、操作文法を切り替える。

相手の身体に複数のIPAを配置:

- 頭
- 腹
- 脛

例:

- 頭: `/æ/`
- 腹: `/ʌ/`
- 脛: `/ɪ/`

出題された音に対応する位置へ蹴りを入れる。

### 狙い

遠距離:
**飛来する記号 / 音への反応**

近距離:
**身体上に配置された記号への瞬間判断**

同じ知識を違う身体課題で反復する。

参考にしているのは『飛龍の拳』の「上・中・下段を読む」構造であり、見た目そのものの模倣ではない。

---

## 2.3 Vocabulary Rush

相手を大きく崩した後のカタルシス。

- 短時間、タップするたびに鞠 / 単語を連射
- そのラウンドで出た語彙を中心に再提示
- 単語音声も連続再生
- BGM / SE / 画面演出は最大密度
- 通常ラリーとは逆方向に、**単語 → 音 → IPA** の再連想も狙う

学習的には「直前に扱った語彙の高速再提示」。
ゲーム的には必殺ラッシュ。

---

# 3. セルルック3D構想

## 3.1 定義

中身は3D空間・3Dキャラクターだが、陰影・輪郭・質感をアニメ / 漫画的に処理する。

### 今回との相性

- 本当に距離を詰められる
- Depth方向へ吹き飛ばせる
- カメラを大きく回せる
- 「表舞台」と「奥舞台」を同じ3D空間で連結しやすい
- 頭 / 腹 / 脛にIPAを浮かせても違和感が少ない
- 水飛沫、残像、集中線、巨大単語、ヒットストップ等の誇張が似合う
- リアル3Dほど質感の粗が目立ちにくく、個人試作でもスタイルとして成立しやすい

方向性を一言で言えば:

> **空間は3D格闘、キャラと演出はアニメ。**

『風のタクト』のように、3D空間を使いながらアニメ的な面と影で見せる方向が原点に近い。

---

# 4. 音楽とラリー

発想の原点のひとつは『風のタクト』の戦闘で、攻撃の応酬に合わせて音楽が反応し、高揚していく感覚。

## 4.1 重要原則

BGMが勝手に進むのではなく、**正しい入力が音楽を増やす**。

成功ごとに:

- 弦
- 打楽器
- 和楽器的レイヤー
- アクセント
- 低音
- 環境音

などを追加・変化させる。

Rally Heatと同期させる。

## 4.2 GIONの特殊構造

GIONは通常ステージの「0 → 100」ではなく、

> **最初から100で始まり、130 → 160 → 200へ上げる**

最終ステージ。

開始は**笙**。

- 暗めの導入
- 笙の持続音
- `GION` 表示
- 鉾・提灯・群衆が見えてくる
- 祭囃子 / 笛 / 打楽器
- さらに弦・ゲーム音楽的編成が重なる

Round 2などで一度笙だけに戻してから再爆発させる案もある。

# 5. 礼

『カラテカ』的な「礼」の記憶は、現行実装ですでに重要な体験要素になっている。

今後も単なる開始ボタンにしない。

## 役割

- 戦いの前の「間」
- 技の継承者同士という儀式感
- 前半の秩序と、終盤の熱狂の対比
- ステージ人格の表現

開始時は礼をする。
しかしラリーが高まり、近距離へ入り、宿命の決戦へ進むほど、最初の秩序が崩れていく。

# 6. Depth Break / 奥舞台

## 6.1 基本アイデア

『アーバンチャンピオン』の「相手を画面端まで追い込み、吹き飛ばすと次の場面へスクロールする」感覚と、3D格闘ゲームの軸回転 / 奥行き移動を組み合わせる。

相手をダウンさせると:

1. 相手がもんどり打って画面奥へ転がる
2. カメラが追う
3. 背景が大きく回転
4. Depth方向へ移動
5. 同じステージの別の顔へ到達
6. 戦い再開

仮称:

- システム名: **Depth Break**
- 世界内呼称: **奥舞台**

### 設計上の意味

> **ダウンを勝敗処理ではなく、空間転換のトリガーにする。**

これにより「見た目が3D」ではなく「遊びが3D」になる。

---

# 7. 表舞台 / 奥舞台

## 7.1 世界観上の基本構造

各ステージは二つの顔を持つ。

### 表舞台

- 人が見ている
- 公の勝負
- 見世物
- 華やか
- 技を披露する
- 観客がいる

### 奥舞台

- 人が消える / 減る
- 静かになる
- 相手を追う / 追われる
- 鞠を奪う / 守る
- 流派の宿命が前に出る
- 勝負が「競技」から「決戦」へ変わる

重要な設計原理:

> **表舞台は情報量が多い。奥舞台は意味が重い。**

GIONのように奥でも熱量が落ちない例外はあるが、熱狂の種類が「群衆」から「殺気」へ変わる。

流派の継承には、**7つと1つの鞠**が関わる。

連想軸:

- 北斗七星
- 北極星
- 方角
- 導き
- 中心
- 宿命

意味は最初から全部説明しない。

紋様、ロゴ、勝利演出、背景意匠、最終局面などに少しずつ出す。

## 8.3 公の試合と宿命の決戦

前半:
**技を見せる勝負**

後半:
**もう引けない勝負**

プレイヤーは最初、奇妙な発音記号蹴鞠ゲームとして入る。
進むほど「この人たちは何かを背負っている」と感じる。
説明ではなくステージ構造で伝える。

# 9. 京都ステージの設計原理

京都を正確に再現しない。

目標は:

> **京都の記憶・記号を、格闘ゲーム用に圧縮・誇張・再配線する。**

個々の建物や記号は「それっぽい」。
しかし隣接関係、縮尺、方角、時代、季節は大胆に崩してよい。

京都を知らない人:
「京都だ！」

京都を知っている人:
「いやいやいや、その位置関係どうなってんねん」

という二重反応を狙う。

### 学習内容は正確に、世界は自信満々に間違える

IPA・音・代表語など学習内容は正確に保つ。
一方、舞台の京都は演出上の嘘を許容する。

# 12. ステージ遷移の共通文法

Depth Breakは全ステージ同じ演出にしない。

例:

- **GION**: 水を跳ね上げて路地へ吹き飛ぶ
- **33GENDO**: 柱の間を奥へ飛び、カメラが長堂を駆け抜ける
- **JINGU**: 大鳥居前から吹き飛び、視界が回転して無限白砂が現れる
- **SANJO STEPS**: 階段を転げ、高瀬川側へ落ちる
- **LATE GAME CENTER**: 扉を抜けて店内 / 裏へ
- **MILLION**: 大学構内へ逃げ込み、講堂へ
- **COHI**: 派手に吹き飛ばすより、静かに路地へ追い込む
- **CHION**: 鐘の一撃と同時に吹き飛び、暗転気味に枝垂桜へ

共通する意味は:

> **「倒す → 次背景」ではなく、「逃げた相手を奥へ追う」。**

観客はついてこない。
主人公だけが追う。

# 14. 試作可能な構造

# 19. 現時点の要約

# 20. タイトル画面 / 仮タイトル構想

## 20.1 仮タイトル: FIFTEENTH EVER GARDEN

現時点の仮タイトル候補:

> **FIFTEENTH EVER GARDEN**
>
> 略称: **FEG**

この名称は、意味を厳密に説明するためのタイトルではない。

狙いは、FGO や NTE のように**略称だけでも固有名詞として流通しそうな、少し大げさで意味を取り切れない英語タイトル**にすること。また、『ヴァイオレット・エヴァーガーデン』のように、語の意味を完全に解かなくても「作品名としての響き」で受け入れられる長いタイトル感を狙う。

したがって、EVER に後から無理に設定上の意味を割り当てない。タイトルを世界観説明文にしない。

一方で偶然 / 副次的に、FIFTEENTH は龍安寺の15石と接続でき、発音上も /f/ と語末の /θ/ を含むため、発音記号ゲームのタイトルとして妙に相性がよい。この点は説明的に前へ出さず、気づけば面白い程度に留める。

## 20.2 タイトルコール

タイトル画面でSTARTを押したら、一瞬の間 / 暗転を挟み、女性の落ち着いた声で

> **“FIFTEENTH EVER GARDEN.”**

とフルタイトルを読み上げる。

狙い:

- タイトルを「読む文字」ではなく「聞く固有名詞」にする
- 最初の1秒から音を意識させる
- 叫ぶのではなく、静か・少し無機質・低めの女性声を基本案とする
- 教材的に /f/ や /θ/ を強調しすぎない

タイトルコール後、そのまま対戦相手選択へ遷移する。

# 21. 石庭の対戦相手選択画面

## 21.1 京都地図ではなく龍安寺の石庭

通常の「京都市内マップ」は使わず、**龍安寺の石庭を上から見たような15石の画面**を対戦相手選択UIにする。

重要なのは、15石すべてをゲーム機能にしないこと。

- 石は15個ある
- そのうち7石だけが後継者に対応する
- 7石のうち1石はプレイヤー自身
- 残る6石が選択可能な対戦相手
- 対戦相手を選ぶと、その人物に対応する京都各地のステージへ移動する
- 残り8石は、**石庭としてそこにある石**であり、現時点ではゲーム上の役割を持たせない

### 重要なトーン

残り8石に「八門」「封印」「隠された流派」などの設定を足して埋めない。

むしろ昔のゲームに時々あった、

> 「ああ、ここ何か実装する予定だったのかな」

という**未実装感 / 余白**を少し残す。

これは世界観上の伏線ではなく、機能をすべて埋めないことによる質感。内部的な冗談としては「足るを知る」ではなく「要件が足りていない」に近いが、製品上は説明しない。

## 21.2 石から京都各地へ飛ぶ

石は京都の地理的位置を示すピンではない。

**石 = 後継者**であり、選ぶとその人物のいる場所へ遷移する。

候補ステージは現時点で以下:

- MILLION / 百万遍
- JINGU / 平安神宮
- SANJO STEPS / 三条通・高瀬川
- NISHIKYOGOKU / LATE GAME CENTER
- 33GENDO / 三十三間堂
- KYOTO STATION
- GION / 四条・八坂・祇園（最終局面候補）

6人の通常後継者と最終局面の割り当ては未確定。ステージ選択順は固定せず、学習上「苦手な4音セットへ再挑戦できる」ことを優先する。

## 21.3 学習UIとしての意味

石庭選択は世界観演出だけでなく、復習選択画面でもある。

各後継者 / 流派に4音セットを対応させ、プレイヤーが好きな順で挑戦できるようにする。

例:

- /θ/ /ð/ /ʃ/ /ʒ/
- /f/ /v/ /s/ /z/
- /p/ /b/ /t/ /d/
- /k/ /g/ /tʃ/ /dʒ/
- /r/ /l/ /w/ /j/
- 母音セット（例 /æ/ /ɪ/ /ʌ/ /ɑ/ または /æ/ /ʌ/ /ɑ/ /ə/）

これにより、

> **対戦相手を選ぶ = 今日練習したい音のデッキを選ぶ**

になる。

現行の PRACTICE → 礼 → HAJIME と相性がよく、一本道の格闘ゲーム進行より、学習ゲームとして自然な構造を優先する。

## 21.4 試作可能な最小構造

まずは以下だけで成立する。

1. 白砂 + 15石の俯瞰 / 斜め俯瞰
2. 7石だけに後継者情報を内部的に割り当てる
3. 自分の1石は選択不可または現在地表示
4. 6石を対戦相手として選択可能にする
5. 石選択で相手名 / 4音セット / 習熟情報を控えめに表示
6. 決定するとステージ名へ遷移
7. 残り8石は触れても何も起きない、または小さな石音だけ返す程度

## 21.5 検証項目

- 15石がまず「石庭」に見え、その後に選択UIだと理解できるか
- 7石だけが機能することで、単なる7ボタンUIに見えないか
- 残り8石の無機能さが混乱ではなく余白 / 昔のゲーム的質感として受け取られるか
- 4音セット / 苦手度の情報を出しすぎて石庭の静けさを壊さないか
- タイトルコール → 石庭 → 京都ステージ、の遷移だけで作品の固有感が立つか
