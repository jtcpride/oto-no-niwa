# v0.34 五人の実モデル調整

2026-10-04 JST。基点 `c7e8fed`、ゲーム版 `0.34.0-five-fighters`。
対象はルカ、壬生宗吉、粟田澄、北山ナギ、御池コタ。承認済み [七人のAI参考画](../seven-v032-concept.png) と実モデルを比較した。今回は画像生成を追加せず、立体モデルを修正して描画・比較を3回繰り返した。

## 何を変えたか

| 人物 | モデルの変更 |
|---|---|
| ルカ | コートを腰で絞って裾を開き、襟を布に沿わせた。赤いインナーにV字の開きを作り、首とのつながりを修正。顎の幅、顔脇の髪、後ろで結んだ毛束を調整。 |
| 宗吉 | 顎髭と口髭を見える位置へ。口元が髭に埋もれない大きさに調整。作業ベストの前身頃と襟・ポケットをつなぎ、裾で広がっていた脚を細くした。 |
| 澄 | 顔の縦長さと鼻を抑え、眉・瞳・口元を調整。袴を長く、腰と袖を細くして、帯の結び目と襞を布に沿わせた。 |
| ナギ | 顔の比率と目・眉・口元を調整。ボブを顎に沿わせ、左右の長さに差を付けた。ジャケットの前身頃・襟を作り直し、内側の黒い服がつながって見える形へ。 |
| コタ | 帽子を丸くし、額の留め具を暗色へ。前髪を顔に沿わせ、丸い瞳と少し開いた笑顔へ。パーカーと袖を丸く、すねを足首へ細くした。 |

共通の関節位置、足先、接触点、アニメーション処理は変更していない。主人公・透と烏丸朔は頂点・法線・色・階層・座標・プロファイルを直列化して基点と比較し、ハッシュが完全一致した。[範囲確認](scope-check.json)

## 3回の比較で直したところ

1. 全身の輪郭と服を調整。実描画で宗吉の髭が口元を隠し、ルカの襟が浮き、コタの前髪の板が顔を横切ることを確認。
2. 髭を縮め、ルカのVネックを実際に開き、襟・紐を衣装の面へ密着。コタの前髪も顔の三角形へ密着。澄の髪の突起を抑えた。
3. 二分割の口がコタの口髭のように見えたため一続きに変更。対象五人の瞳を丸くし、澄・ナギ・コタの眉を緩く曲げた。ルカの顎も少し広げた。

`round1/`・`round2/`・`round3/` に途中画像を保存。最終一覧と変更前は同じThree.js、照明、カメラで比較している。AI参考画を画面へ貼り付けてはいない。
