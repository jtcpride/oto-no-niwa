## 狙った差

| 人物 | 今回の変更 |
|---|---|
| ルカ | 頬から顎へ絞る輪郭、細い鼻、短い顔脇の髪と後ろの結び髪。頭頂から生え際まで一続きの形にし、浮いて見える髪の隙間を塞いだ。コートの裾を広げ、パンツの腰を高くして衣装の上下の比率を調整。 |
| 宗吉 | 白い顎髭を顔の三角形へ沿わせ、顎から浮く白い塊を解消。口髭と鼻を小さくし、額と横の白髪を整えた。ベストの裾・胴回りとポケットを少し広くした。 |
| 澄 | 下顔面を短く、顎を細くし、鼻と口を小さく調整。ポニーテールの付け根を高くして結び飾りを追加。袖口を広げ、胸の開きを白い合わせ襟へ変更。襟の下は板状の肌をやめ、立体の首につないだ。 |
| ナギ | 頬を残して顎を細くし、少し開く笑顔へ。ボブの片側を短くして耳を見せ、肩を細くした。開いたジャケットの裾に布に沿った淡い帯を追加。 |
| コタ | 小さな鼻・短い顎と開いた笑顔。帽子を丸くして傾け、不揃いの前髪を見せた。帽子内の髪の体積を抑えて突き抜けを修正。パーカーの裾を広げた。 |

対象五人の手に小さな親指を加え、単純な四角い手袋状の輪郭を崩した。関節は増やしていない。対象外の透と朔は、頂点・法線・色・階層・位置・プロファイルを基点と比較しハッシュが完全一致。[範囲検証](scope-check.json)

## 比較中に見つけて直したこと

1. 顔の輪郭、髭の密着、帽子の傾き、髪の非対称性を変更。ルカの追加毛束が頭上の団子に見えた。
2. ルカの頭頂を作り直し、衣装と手を調整。ルカの生え際に肌の隙間が出た。
3. 生え際の高さを周囲に沿って変える形へ変更。宗吉の横髪とコタの下顔面を調整。参考画と別担当の目視でも比較した。
4. コタの髪と帽子の交差、澄の広すぎる胸元、ルカの細い隙間を修正。横顔から見ると澄の板状の肌が浮くことを確認。
5. 澄の板を除去して首を立体でつなぎ直し、正面・斜め・横で浮きがないことを確認。

各段階は `round1/`〜`round5/` に保存。中間画像は完成版ではない。最終比較の変更前・変更後は同じ照明・カメラ・Three.jsで撮影した実モデル。参考画のポーズや描き込みをゲーム内へ画像として貼ってはいない。
