# v0.10 Playtest Notes — feedback / retry / 2.5D down

最終更新: 2026-09-09

このメモは `docs/PROJECT_HANDOFF.md` の追補。v0.9試遊後に出た具体的な改善要求と、その狙いを残す。

## 試遊で出た重要な観察

- `TIME → 礼 → HAJIME` の儀式感は好感触。礼は削らず、むしろ相手も返礼する方向へ。
- 初回プレイはかなり崩れたが、**2回目にはかなりラリーへ食らいつけた**。
- したがって現時点では、本戦を単純に易しくしない。短い反復だけで音と位置の対応が身体化し始める可能性を検証する。
- PRACTICE中、画面中央の「代表語 + 語全体IPA + 狙う記号」が非常に見やすく、視線の置き場として機能した。本戦のフィードバックにも同じ場所を使う。

## v0.10で入れた変更

1. `TIME` を画面表示だけでなく音声でも告げる。
2. TIME後の見送り球は足元で止めず、そのままプレイヤーの後方へ転がす。
3. プレイヤーが礼をしたらCPUも礼を返す。
4. 礼からHAJIMEまでの静かな間を長くし、`HAJIME!` も英語話者TTSで発声する。発音が少し不自然でも、異文化審判のような味として許容する。
5. 正しく返球した後、本戦でも画面中央に **単語 + 語全体IPA + 正解の対象記号** を短く表示する。
6. 不正解時の救済返球は「よろめきながら蹴る」より、**身体に鞠が当たり、偶然跳ね返ってラリーだけは続く BODY RETURN** とする。成功と失敗の身体表現を明確に分ける。
7. 間違えた問題は簡易リトライキューへ入れ、数問後にもう一度出す。
8. 3回連続失敗で、プレイヤーが画面奥または手前方向へもんどり打ってDOWN。ゲームが2.5D空間であることを演出でも見せる。

## この変更で検証したいこと

### 学習面

- 中央フィードバックを見た直後、同じ音の再出題で正答率が上がるか。
- 「代表語 → 発音記号」のアンカーが本戦中にも強化されるか。
- 1回目から2回目への急な改善が再現するか。
- 改善が **聞き分けの上達** なのか、**位置・タイミングへの慣れ** なのかを分けて観察する。

### ゲーム面

- BODY RETURNなら、不正解が一目で分かる一方、ラリーの流れは保てるか。
- 三連続ミスのDOWNは罰として重すぎず、むしろ失敗を面白い出来事へ変えられるか。
- TIME音声 → 見送り → 相互礼 → 間 → HAJIME音声、で本戦前の緊張が十分に立ち上がるか。

## 壊さないこと

- 礼を合理化して単なる「開始ボタン」にしない。
- 再礼で開始待ち時間がリセットされ、理論上いつまでも礼できる挙動は残す。
- 現在の少し理不尽なスポーツ難度を、学習ゲームだからという理由だけで平坦化しない。
- なぜ `TIME` と `HAJIME` が混在しているのか説明しない。
