比較の声は、両方とも同梱の録音音声です。
  • 0〜18秒：鼓に琴の実入力が重なり、控えめなループと鈴が育つ。
  • 19〜31秒：奥の院へ。鼓が速くなり、三味線と太鼓が加わる。
  • 31.3秒：ミスで重なりが引く。続く正解で育て直す。
  • 37.4秒〜：既存のVocabulary Rushへ。読み上げは次の語で上書き。

琴のループは8拍。新しい6打までを残し、繰り返すたびに薄くして3周で消します。相手と自分の蹴りで和の音階を一段ずつ上げ、上限を設けています。発音が自然に終わると短い楽器の返事が入ります。

これは実Web Audio出力の比較録音です。蹴り順と局面を同じ時刻に送った音の比較で、通常プレイの録画ではありません。Mac Chromeの進行・音声APIは別途検証。iPhone／iPad Safariの実出力・聞き取りやすさ、旧音声に伴うOSの音量低下は未確認です。鞠の飛行時間と判定猶予は維持しています。
