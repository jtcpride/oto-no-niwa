## 検証結果と未検証を混同しない

実装コード＋DOM入力の決定的テストで、京都駅→6人自由順→保存→GION→影→散開→再挑戦まで通過。敗北・再戦・消音・演出OFF・重複開始・礼の繰返し・中断復帰・壊れた保存値も試験しています。既存基点と8種類の球道・時間・判定・ダメージが一致しました。

以下はMacへの転送前のクラウド環境の制約です。Macの結果は冒頭リンクを参照してください。

- `/usr/bin/chromium` は `process_singleton_posix.cc socket() failed: Operation not permitted` でページ作成前に停止。許可された再試行でも同じ。AF_UNIXがEPERM
- `--use-gl=angle --use-angle=swiftshader --enable-unsafe-swiftshader` のソフトウェアGL起動も上記の段階で停止。GPU描画試験を実行できたという意味ではない
- クラウドブラウザでは公開済み v0.29.1 自体が「3D表示できません / WEBGL REQUIRED」。新実装の故障と確定したわけではないが、動作保証にもならない
- 画像証拠はコード内の立体とカメラをCPUで投影したもの。WebGLスクリーンショット、CSS配置確認、実機試遊の証拠ではない
- iPhone/iPadのBGM、SE、発音、タッチ、画面ロック復帰は未確認

Macでは実WebGLを追加検証済みです。実機の聴感・タッチまで受入済みの公開完成版ではありません。

## 再現コマンド

Node.js 22以降を推奨（ここでは24.19.0）。製品自体はビルド依存なしの静的HTML/JavaScriptです。

```sh
npm install
npm test
node tests/assemble.cjs /tmp/feg-v030.html
python3 -m http.server 8765
```

`npm test` は合成・内容検査・教材・保存モデル・音声ライフサイクル・人物接触・舞台構造・DOM通し試験です。WebGL/実音声は保証しません。

```sh
CHROME_PATH=/path/to/chrome node tests/complete-browser-v030.cjs
```

過去の `battle-v016` / `stages-v021` / `feel-v023` などは旧メニューや音量・舞台IDを前提にしています。新キャンペーンには新しい統合試験を使用し、基点は `tests/fixtures/baseline-v0291.html` と比較します。旧 `feel-v023` のbreak/back時刻不一致は基点時点にも存在します。旧試験が全て新実装で成功したと記載しないでください。
